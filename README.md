Synthesizes AI cinema prompts, camera choreography parameters, diffusion image recipes, and multi-track audio compositions within an obsidian dark aesthetic.

## 🌟 Key Features

- **Director Prompt Choreographer**: Craft structured generation prompts with camera focal lengths, shutter angles, lighting schemas, and motion velocity tags.
- **Aspect Ratio & Resolution Matrix**: Instant preview switching between 16:9 Cinema, 9:16 Vertical Shorts/Reels, 1:1 Square, and 2.39:1 Anamorphic widescreen.
- **Diffusion Style Presets**: Built-in visual profiles for Cyberpunk Neon, 35mm Analog Film Grain, Hyper-real Unreal Engine 5, Anime Cel-Shading, and Documentary realism.
- **Audio & Foley Composer**: Generate ambient soundscapes, soundtrack cues, and synthesized sound effects matching scene mood.
- **Cloud Gallery & Asset Exporter**: Save, categorize, tag, and export creative parameters directly to JSON or markdown.

## 🚀 Running Locally

### Prerequisites

- [Node.js 18+](https://nodejs.org/)

### Quickstart

```bash
# Clone the repository
git clone https://github.com/umutocguder/11aicreate.git
cd 11aicreate

# Install dependencies
npm install

# Run automated tests
npm test

# Start local server
npm start
```

Visit [http://localhost:3000](http://localhost:3000) to open the creation studio.
